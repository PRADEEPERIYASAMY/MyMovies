# Support

This document explains where to go for help with MyMovies.

---

## Before Asking for Help

1. Read the [README](README.md), especially sections 3, 5, and 8, which cover the architecture, data flow, and getting-started steps.
2. Search [existing GitHub Issues](https://github.com/PRADEEPERIYASAMY/MyMovies/issues) to see if your question has already been answered.
3. Check the [Known Rough Edges & Roadmap](README.md#7-known-rough-edges--roadmap) section. Your issue might already be tracked.

---

## How to Get Help

### GitHub Issues (preferred)

Open a [new issue](https://github.com/PRADEEPERIYASAMY/MyMovies/issues/new) with as much detail as possible:

- Your Android version and device or emulator API level
- The exact steps that lead to the problem
- What you expected to happen vs. what actually happened
- Logcat output, crash traces, or a screen recording if applicable

Label your issue appropriately:

| Label | When to use |
|---|---|
| `bug` | Something is broken or behaving incorrectly |
| `question` | General usage or architecture questions |
| `enhancement` | A feature you would like to see added |
| `documentation` | Corrections or additions to docs |

---

## What This Project Does NOT Support

- Issues related to third-party API availability (movie catalog API, OpenSubtitles) are outside the scope of this project. Those services operate independently.
- Questions about rooted devices, custom ROMs, or non-standard Android environments.
- Requests for help with your own fork or a modified version of the codebase.

---

## Security Issues

**Do not open a public issue for security vulnerabilities.** See [SECURITY.md](SECURITY.md) for the correct reporting process.

---

## Response Expectations

This is a solo-maintained project. Response times are best-effort. Issues that include clear reproduction steps and sufficient context are resolved significantly faster than vague reports.
